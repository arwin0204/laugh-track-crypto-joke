A one-line crypto trading joke for make.fun's "Laugh Track: The Crypto Trading Joke Contest" bounty, $2 in USDC. The program writes a single original joke about crypto and trading life — under 200 characters — to `entry.txt` in the grader-supplied output directory, and nowhere else.

The joke: "My trading strategy is simple: buy high, sell low, and call it dollar-cost averaging with extra steps."

## Run it

```sh
python3 main.py /output
```

Test it locally first:

```sh
python3 main.py /tmp/test-output && cat /tmp/test-output/entry.txt
```
